## Requirements and practical limitations

The included Upright Piano is available offline. MIDI recording and user-instrument import require Pro and sufficient local storage. Studio accepts compatible SF2 and DLS sound banks, or a flat folder containing one EXS instrument and its WAV samples. The import limit is 1 GiB per instrument, including samples, and 256 files per EXS folder, including the EXS definition. EXS subfolders are not supported. Each sound-bank file provides one instrument choice using the first preset reported by Apple's sampler; AudioShift does not provide a browser for all presets in a bank. Not every file with a supported extension will work. Plugins and executable instrument code are not supported.

Instrument and editor imports copy selected content without changing the originals; the music library instead references the folder you select. Import checks reduce file-handling risks but do not establish ownership or guarantee compatibility. Hardware input/output requires a compatible device and any necessary permissions. Available export formats depend on system support.

Chord, key, tempo, and lyric analysis provides estimates for practice, not guaranteed transcription. Lyric drafts require compatible iOS/iPadOS 26 or later hardware and an Apple-supported language; a language-model download may be needed. Tuning and level readings depend on input, calibration, and surroundings. Sound Meter is not certified equipment for health, occupational-safety, or regulatory measurements. Keep listening levels safe and review results before relying on them. Compatibility with every file or peripheral is not promised.

## Sampler instruments

The Pro Sampler lets you make instruments from your own audio files, recordings, and compatible imported instruments, without downloading additional sample libraries. Sampler editing, live playback, and using sampler instruments for new Studio MIDI renders require Pro. Audio-sample pitch can follow the played note while preserving playback duration, rather than speeding up or slowing down the sample. Large pitch changes can introduce audible artefacts. Imported sound banks use their own sample mappings and playback behaviour.

Audio imports must be readable mono or stereo files, between 0.01 seconds and 30 minutes, at 8-192 kHz, and no larger than 512 MiB per source file. Imported audio is decoded into local CAF files, which can be larger than the source. Projects allow up to 64 zones, with a 2 GB storage budget for project imports and recordings, including retained audio/revisions. Play mode preloads selected sample ranges with a 128 MiB decoded stereo-audio budget; a compressed file's size does not tell you how much playback memory it needs. Banks, effects, and the rest of the app need additional memory. These are limits, not guarantees that every project will perform reliably on every device. Test your complete setup before a performance and keep backups.

Sampler also accepts the compatible bank formats described above, plus a limited SFZ import: select a folder with one SFZ definition and its WAV samples. Only sample assignment, key/range/root, gain, pan, and fine tuning are supported; other commands are rejected rather than silently approximated. SFZ import is limited to 64 regions within the project's 64 zones, 256 files including the definition, and 1 GiB of source content, with at most two nested folder levels. The audio-import limits above also apply to its samples. SFZ is not a direct Studio import format; a compatible Sampler instrument can be enabled for Studio. Size limits use MiB/GiB for binary units and GB for decimal units.
